# AI拍卖搜索 - 产品需求文档 (PRD)

## 1. 产品概述

**产品名称**: AI拍卖搜索助手  
**目标场景**: 阿里拍卖  
**核心功能**: 基于用户自然语言描述的购买需求，通过 AI 向量检索匹配拍卖资产，以对话方式呈现推荐结果  
**开发周期**: 1人/天  
**架构**: 前后端分离（React + Python）

## 2. 用户角色

| 角色 | 说明 |
|------|------|
| VIP客户 | 点击"我要买"后，在对话框中描述购买需求，获得 AI 推荐的匹配资产 |
| 管理员 | 导入 Excel 资产数据，管理资产库 |

## 3. 功能需求

### 3.1 资产管理（管理员）

- **Excel导入**: 管理员上传 Excel 文件，系统自动解析资产信息
- **自动向量化**: 导入的资产自动生成向量嵌入，存入 ChromaDB
- **资产列表**: 查看所有已导入资产，支持分页
- **资产删除**: 管理员可删除单条或批量删除资产

### 3.2 智能搜索（VIP客户）

- **对话框交互**: 用户在对话框中输入自然语言描述的购买需求
- **向量匹配**: 系统对用户输入进行向量化，在 ChromaDB 中检索相似资产
- **思维链展示**: 对话框中展示 AI 的匹配推理过程（需求分析 → 向量检索 → 相似度排序）
- **商品列表展示**: 匹配结果以商品卡片列表形式在对话框内展示

### 3.3 Excel 格式规范

| 列名 | 说明 | 必填 |
|------|------|------|
| 标题 | 资产名称 | 是 |
| 描述 | 资产详细描述 | 否 |
| 类别 | 资产分类（住宅/商铺/车辆/土地/设备等） | 否 |
| 所在地 | 资产所在城市/地区 | 否 |
| 起拍价 | 起拍价格（元） | 否 |
| 状态 | 拍卖状态 | 否 |

## 4. 技术架构

```
┌─────────────┐     HTTP/REST     ┌──────────────┐     向量检索     ┌──────────┐
│  React 前端  │ ◄──────────────► │ FastAPI 后端  │ ◄─────────────► │ ChromaDB │
│  (Vite+AntD) │                  │  (Python)     │                 │ (向量库)  │
└─────────────┘                   └──────────────┘                  └──────────┘
```

### 4.1 后端

- **框架**: FastAPI
- **向量数据库**: ChromaDB（本地持久化）
- **嵌入模型**: ChromaDB 默认嵌入（all-MiniLM-L6-v2）
- **Excel解析**: openpyxl
- **端口**: 8000

### 4.2 前端

- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **UI组件库**: Ant Design 5
- **HTTP客户端**: axios
- **路由**: React Router
- **端口**: 5173（开发模式）

## 5. API 设计

### 5.1 资产管理

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/assets/upload` | 上传 Excel 文件导入资产 |
| GET | `/api/assets` | 获取资产列表（分页） |
| DELETE | `/api/assets/{id}` | 删除单条资产 |
| DELETE | `/api/assets/batch` | 批量删除资产 |
| GET | `/api/assets/stats` | 获取资产统计信息 |

### 5.2 智能搜索

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/chat` | 发送用户消息，返回匹配结果 |

## 6. 交互流程

```
用户 ──► 输入"我想买杭州的三居室住宅"
                    │
                    ▼
AI ──► 展示思维链:
       ├─ 🔍 需求理解: 分析用户需要杭州地区的三居室住宅
       ├─ 📊 向量检索: 在资产库中搜索相似资产...
       ├─ 📋 找到 N 条匹配资产
       └─ ✅ 按相似度排序推荐
                    │
                    ▼
AI ──► 展示匹配资产卡片列表:
       ┌────────────────────────────┐
       │ 🏠 杭州市西湖区三居室住宅    │
       │ 起拍价: ¥350万 | 相似度: 95%│
       └────────────────────────────┘
```
